# 创作需求 Brief

## 目标

为 Codex 多模态实验台生成第一张可用于页面展示的概念主视觉，验证 `Prompt -> imagegen -> public/assets/codex-lab` 的完整闭环。

## 使用场景

- 页面或模块：`/codex-lab` 本地实验页
- 目标用户：项目开发者、内容创作者、工作流测试者
- 最终资产用途：页面资产落点区预览图、实验文档插图、后续概念图风格基准

## 核心画面

- 主体：本地 AI 多模态实验工作台，展示图片分析报告、Prompt 卡片和概念图资产。
- 场景：深色产品工作台，包含项目文件夹、截图输入、结构化报告、Prompt 包、生成图预览。
- 情绪：克制、专业、可靠，同时保留创造力。
- 必须出现：三步闭环的视觉暗示，从截图输入到中文分析，再到概念图输出。
- 必须避免：外部 API Logo、随机品牌、乱码 UI 文本、水印、过度科幻装饰。

## 风格方向

- 风格关键词：dark local AI lab interface, structured workflow cards, prompt pack, concept art asset board, restrained product visual
- 色彩倾向：黑色、炭灰、柔白、酸性黄绿色强调，少量青色细节。
- 构图偏好：16:9 横向，左到右形成输入、推理、输出路径，保留可用于页面排版的负空间。
- 参考素材路径：`experiments/codex-internal-multimodal-lab/input/screenshots/codex-lab-home-1366x900.png`

## 输出规格

- 画幅：16:9
- 建议尺寸：1536x864 或更高比例等价尺寸
- 资产文件名：`concept-hero.png`
- 是否需要透明背景：否

## 备注

生图结果不是实际 UI 截图，不需要复刻页面文字。画面应像高质量产品概念图，便于后续在 `/codex-lab` 页面中作为资产预览使用。
