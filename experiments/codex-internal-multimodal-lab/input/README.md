# Input Guide

这里放本地实验输入素材。不要提交真实密钥、授权截图、用户隐私数据或未脱敏的后台截图。

## 子目录

- `screenshots/`：页面截图、产品截图、UI 状态图、关键帧。
- `references/`：风格参考、角色参考、场景参考、竞品参考。
- `brief.md`：创作需求输入模板。

## 命名建议

```text
screenshots/2026-05-brief-home-empty.png
references/style-ink-interface-01.png
references/character-agent-neutral-01.png
```

文件名尽量描述内容、用途和序号，方便在分析报告里引用。
