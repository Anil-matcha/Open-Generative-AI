## 继续不接入的原因

- 当前目标是评估“Codex 辅助创作”的可用性，不是上线用户侧生成服务。
- 正式 API 接入会引入密钥、计费、权限、队列、失败重试和内容审核等额外系统面。
- 现阶段页面只需要引用已落地的 workspace 静态资产，不需要运行时调用模型。

## 后续接入前置条件

- 明确用户侧触发场景、频率和成本上限。
- 明确模型供应商、鉴权方式、内容安全策略和失败降级方案。
- 增加服务端 API 边界、任务队列、审计日志、测试覆盖与环境变量规范。
- 保证任何密钥只进入本地或部署环境变量，不进入仓库。
