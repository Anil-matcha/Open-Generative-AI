**How upstream effects dropdown works:**
1. **Dropdown Display**: Clicking "Effect" button shows list from `getEffectNamesForModel(selectedModel)`
2. **Selection Logic**: User selects effect → sets `selectedEffectName` variable
3. **API Integration**: In generation, adds `i2vParams.name = selectedEffectName` to API call
4. **API Call**: `muapi.generateI2V(i2vParams)` receives effect as `name` parameter

### 2.5. AI-VFX Reference Implementation Analysis ✅ COMPLETED
**Repository**: `https://github.com/deangilmoreremix/AI-VFX` (fork of SamurAIGPT/AI-VFX)

**Architecture Overview:**
- **Single Page Next.js App**: All effects in one page with filter tabs
- **Effect Categories**: AI Effects (10), Motion Controls (10+), VFX (12)
- **Selection Method**: Click effect thumbnails → sets `selectedEffect` state
- **Generation Flow**: Select effect → input prompt/parameters → generate with API

**Key Implementation Details:**
```javascript
// Effect selection via thumbnail click
onClick={() => setSelectedEffect(effect)}

// API payload construction
const videoPayload = {
  prompt: inputText,
  name: selectedEffect?.name,  // Effect name from selection
  aspect_ratio: selectedAspect,
  size: getMuApiSize(selectedAspect, selectedResolution),
  quality: selectedQuality,
  duration: parseInt(selectedDuration),
  image_url: imageUrl  // Required for effects
};

// API call with effect parameter
const res = await fetch('/api/proxy-muapi', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'x-api-key': userApiKey },
  body: JSON.stringify(videoPayload)
});
```
