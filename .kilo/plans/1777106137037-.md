# Plan: Add UI/UX Files for Remix-Go App

## Overview
Implement the complete UI/UX for the VideoRemix Go application based on the provided specifications. The app is a lite video editor for personalized videos within the VidCloud platform.

### Application Architecture Clarification
- **Main Application**: The main VidCloud app contains `src/components/RemixGoPage.js`, which is an iframe loader that embeds the standalone Remix Go app
- **Standalone Remix Go App**: Located in `apps/remix-go/`, this is a separate Vite React application with its own build process
- **Scope**: We will ONLY modify files within `apps/remix-go/` (the standalone app). The main app's `RemixGoPage.js` will remain unchanged - it simply loads the remix-go app in an iframe at `/apps/remix-go/`

The standalone app is what appears as "Remix Go" in the main app's side menu. Current codebase has basic structure but missing key pages and theming.

## Current State Analysis
- Tech Stack: React + Vite, Tailwind CSS, Zustand (not MobX as described, but compatible)
- Existing: Editor.jsx, Publisher.jsx, basic routing
- Missing: GettingStarted page, dark theme, glass-morphism effects, wizard flow
