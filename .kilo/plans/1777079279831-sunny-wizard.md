# Plan: Implement Figma Design for Remix-Go Template Generator

## Goal
Implement the provided Figma design for the AI template generator with pixel-perfect accuracy, integrating it into the remix-go video editor application.

## Context
- **Application**: remix-go is a standalone video editor app located at `apps/remix-go/`
- **Current State**: Existing React app with video editing capabilities, AI generation modals (AIGeneratePanel, ScriptWriter, etc.)
- **Design Source**: Figma design link provided by user
- **Requirements**: Adapt Figma design to remix-go app styling, maintain existing functionality, ensure responsive design and accessibility

## Prerequisites
- Figma MCP server connected and accessible
- Confirmed Figma design link: https://www.figma.com/design/fee46kCF9u8ebxxWTi0eYU/Template-Generator?node-id=1-2&t=fXp4Xy9v8a0jiCNR-1
- Design system tokens mapped to remix-go app color scheme (light theme with gray backgrounds, blue accents)

## Workflow (Using Superpowers + Figma Skills)

### Phase 1: Design Analysis (Brainstorming)
1. **Extract Figma Parameters**
   - Parse Figma URL to get fileKey and nodeId
   - Validate MCP server connection
   - Confirm design scope (component/frame level)

2. **Fetch Design Context**
   - Run `get_design_context(fileKey, nodeId)` for structured data
   - Run `get_metadata(fileKey, nodeId)` if design is complex
   - Download required assets (images, icons, SVGs)

3. **Visual Reference**
   - Capture screenshot with `get_screenshot(fileKey, nodeId)`
   - Establish baseline for validation

### Phase 2: Implementation Planning (TDD Approach)
4. **Component Analysis**
   - Identify existing remix-go modals and components that can be reused
   - Map Figma design tokens to remix-go color scheme (gray-50 backgrounds, blue/gray accents)
   - Break down into 2-5 minute tasks per component

5. **Test Planning**
   - Define visual regression tests
   - Plan accessibility validation (WCAG)
   - Set up responsive testing scenarios

### Phase 3: Development Execution (Subagent-Driven)
6. **Component Implementation**
   - Create/modify components following project conventions
   - Implement responsive behavior
   - Add TypeScript types and documentation

7. **Integration**
   - Add new template generator route to remix-go app routing
   - Integrate with existing modal system and AI generation functionality
   - Ensure compatibility with video editor workflow

### Phase 4: Validation & Review
8. **Visual Parity Check**
   - Side-by-side comparison with Figma screenshot
   - Validate layout, typography, colors, spacing
   - Test interactive states (hover, active, disabled)

9. **Functionality Testing**
   - Run existing test suite
   - Add new tests for implemented features
   - Cross-browser validation

10. **Code Review**
    - Systematic review against plan
    - Check for design system compliance
    - Validate accessibility standards

### Phase 5: Deployment
11. **Branch Management**
    - Verify tests pass on clean baseline
    - Present merge/PR options
    - Clean up development workspace

## Success Criteria
- ✅ Pixel-perfect visual match with Figma design
- ✅ All interactive states functional
- ✅ Responsive across devices
- ✅ Accessibility compliant (WCAG AA)
- ✅ Tests passing
- ✅ No breaking changes to existing functionality

## Risk Mitigation
- **Complex Designs**: Use metadata to break down into manageable chunks
- **Asset Issues**: Verify MCP server assets endpoint accessibility
- **Token Conflicts**: Prefer project design system but adjust for visual fidelity
- **Performance**: Optimize for video editor integration and AI generation workflows
