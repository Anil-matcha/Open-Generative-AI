### Phase 3: Writing Plans (Task Breakdown)

#### Task 3.1: Audit Hero Header Positioning
**File**: All studio components

- Uses `w-full` and proper height classes (`h-64 md:h-80 lg:h-96`)

#### Task 3.2: Fix App Control Positioning (Centered, Not Right)
**Goal**: **Center controls** in container (not push right)

**Approach**:
- Examine each app's layout structure
- Add `justify-center` to control containers (not `justify-end` or `ml-auto`)
- Ensure controls are in a `flex` container with proper alignment
- Use `items-center` for vertical centering

**CSS Pattern**:
```css
.controls-container {
  display: flex;
  justify-content: center; /* CENTER, not right */
  align-items: center; /* vertical center */
  width: 100%;
}
```

**Update for All Apps**:
- `src/components/HeadshotStudioPage.js`

- `src/components/SendsparkPage.js`

- `src/components/MarketingStudioPage.js`
- All other studio components with controls

#### Task 3.3: Make Pages Non-Scrollable
**Goal**: Page itself isn't scroll, only inner panels

**Approach**:
- Set page root: `height: 100vh; overflow: hidden;`
- Inner content area: `flex: 1; overflow-y: auto;`
- Preserve dropdown/modal scrollability

**CSS Pattern**:
```css
.page-root {
  height: 100vh;
  overflow: hidden;
  display: flex;
  flex-direction: column;
}
.content-area {
  flex: 1;
  overflow-y: auto; /* only this scrolls */
}
```

#### Task 3.4: Remove Dead Space
**Goal**: No unnecessary gaps under header.

**Check**:
- No `margin-top` or `padding-top` on content area unless dropdown is open
- Hero banner uses `mb-4` (reasonable gap)
- Next element starts immediately after hero

**Fix**: Remove unnecessary `mt-*` classes on content containers.

#### Task 3.5: Runway ML Design Verification

### Low Risk

### Medium Risk
- Layout changes might affect mobile responsiveness
- Scroll changes could impact dropdown/modal behavior.

### Mitigation
- Test on multiple screen sizes
- Ensure dropdowns/modals still scroll properly
- Keep fallback for special cases (e.g., timeline editor may need scroll).
