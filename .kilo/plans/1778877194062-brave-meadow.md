# Sign In Page Implementation Plan

## Overview
Create a sign-in page designed like the landing page with password-based authentication (no email confirmation) and add password change functionality to settings that saves to Supabase.

## Current State Analysis

### Existing Authentication
- `apps/videco-ai-platform/pages/auth/login.tsx` - Existing Next.js login with Supabase Auth UI
- `src/lib/supabase-client.ts` - Supabase client for main app
- `apps/remix-go/src/lib/api.js` - API with `signInWithPassword` and `updateUser` methods

### Landing Page Structure
- `src/components/landing/LandingPage.jsx` - Full-page landing component
- `src/components/landing/common/Header.jsx` - Landing header with "Sign In" and "Get Started" buttons
- No app shell wrapper for landing page (full-page design)

### Settings Page
- `src/routes/Settings.tsx` - React/TS settings page with brand, integrations, billing, team tabs
- No password change functionality currently

## Implementation Plan

### 1. Create SignInPage Component
**Location:** `src/components/landing/SignInPage.jsx`

**Design Requirements:**
- Match landing page aesthetic (dark theme, cyan accents, glassmorphism)
- Full-page layout (no app shell)
- Same header as landing page but with modified nav buttons

**Component Structure:**
```jsx
- Header (landing style)
- Main content area
  - Sign in form
    - Email input
    - Password input
    - Submit button
    - Forgot password link
  - Sign up link
- Footer (optional)
```

**Form Fields:**
- Email (type: email)
- Password (type: password)
- Remember me checkbox (optional)

**Features:**
- Form validation
- Loading state on submit
- Error handling
- Success redirect

### 2. Add Password Change to Settings
**Location:** `src/routes/Settings.tsx`

**New Tab:** "Account" tab alongside existing tabs

**Fields:**
- Current password (type: password)
- New password (type: password)
- Confirm password (type: password)

**Functionality:**
- Validate passwords match
- Call Supabase `updateUser` with new password
- Show success/error messages

### 3. Update Router
**Location:** `src/lib/router.js`

**Add route:**
```js
'signin': () => import('../components/landing/SignInPage.jsx').then(m => m.SignInPage()),
```

### 4. Update Main Entry Point
**Location:** `src/main.js`

**Changes:**
- Handle `signin` page like `landing` (full-page, no app shell)
- Add navigation listener for sign-in/sign-up flows

### 5. Update Landing Header
**Location:** `src/components/landing/common/Header.jsx`

**Changes:**
- Modify "Sign In" button to navigate to `/signin`
- "Get Started" button should trigger sign-up flow

### 6. Password Update Service
**Location:** `src/lib/supabase-client.ts`

**Add function:**
```typescript
export async function updateUserPassword(currentPassword: string, newPassword: string) {
  const { data, error } = await supabase.auth.updateUser({
    password: newPassword
  });
  return { data, error };
}
```

## Technical Details

### Supabase Authentication
- Use `supabase.auth.signInWithPassword({ email, password })` for sign in
- Use `supabase.auth.updateUser({ password: newPassword })` for password change
- No email confirmation required (user specified)

### State Management
- Local component state for form fields
- No global state needed for auth (Supabase handles session)

### Styling
- Use existing landing page CSS variables
- Tailwind classes (already in use)
- Consistent with dark theme: `bg-[#020205]`, `text-white`
- Cyan accent: `text-cyan-400`, `bg-cyan-400`

### Error Handling
- Display errors inline in form
- Network error handling
- Validation errors

### Navigation Flow
```
Landing Page → Sign In → Dashboard/Home
            → Get Started → Sign Up → Dashboard/Home
```

## Testing Considerations
- Form validation works correctly
- Error messages display properly
- Password change validates old password
- Successful sign-in redirects appropriately
- Mobile responsiveness

## Security Considerations
- Password requirements enforced by Supabase
- No passwords logged
- Secure password update (requires current session)
- CSRF protection via Supabase
