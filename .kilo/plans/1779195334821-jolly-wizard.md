# Shell App Rescue & Full Module Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert 4 existing shell apps (Remix Go, Vibe Workflow, Open Pomelli, AI Headshot Generator) and create/fix 4 new apps (Marketing Studio, Workflows, Agents, Design Agent) into full AI-VFX-style standalone Higgsfield modules with real UI, services, generation flows, Supabase persistence, Library save, and handoff to Render/Director/Timeline/Edit Studio.

**Architecture:** Audit-first approach using AI-VFX as the reference pattern (Next.js-style app with components/hooks/lib/services/API adapters). Each app becomes a self-contained `src/apps/[app-id]/` module exporting App, manifest, routes, service. Shared `src/lib/` bridges handle output handoff, MuAPI/OpenAI adapters, media storage. All server secrets via Netlify/Supabase Edge Functions. Supabase for persistence replacing SQLite/Prisma/NextAuth. No root layout takeover; existing Higgsfield apps preserved.

**Tech Stack:** Higgsfield React frontend + Supabase (DB/Storage/Edge) + MuAPI (generation) + OpenAI (LLM/planning) + Netlify Functions (secure proxy) + Tailwind/glassmorphism cinematic UI.
