# Feature Gating Plan: Timeline Editor, Director Editing, and AI Features

## Overview

This plan outlines the implementation of a comprehensive feature gating system for selling apps individually and offering AI as an upgrade tier. The system will gate:

1. **Core Apps**: Timeline Editor, Director Editing, and other standalone apps (each sold individually)
2. **AI Features**: All AI-powered capabilities as a single gated product (not tiered within the app)

## Architecture

### 1. Subscription Tier Model

```
FREE TIER
├── Basic Timeline Editor (watermarked exports)
├── Manual editing tools
└── Standard export formats

APPS (sold individually)
├── Director Editing ($49 one-time or $9/month)
├── Image Studio ($29 one-time or $5/month)
├── Video Studio ($39 one-time or $7/month)
└── Templates Pack ($19 one-time)

AI PRODUCT (gated together)
├── AI Features ($29/month or $199/year)
├── All AI agents included
├── Unlimited AI processing
├── Priority queue
└── Commercial license
```

**Key Change**: Director Editing is now a standalone product (not tier-gated). AI features are sold as a single product with all capabilities included, not split across tiers.

### 2. Implementation Layers

#### Layer 1: Feature Flag System (`src/lib/featureFlags.js`)
```javascript
const FEATURES = {
  // Apps (sold individually)
  'timeline-editor': { tier: 'free', credits: 0 },
  'director-editing': { tier: 'app', price: 49, credits: 0 },
  'image-studio': { tier: 'app', price: 29, credits: 0 },
  'video-studio': { tier: 'app', price: 39, credits: 0 },
  
  // AI Features (single product, all included)
  'ai-video-generation': { tier: 'ai-product', credits: 0 },
  'ai-image-generation': { tier: 'ai-product', credits: 0 },
  'ai-background-removal': { tier: 'ai-product', credits: 0 },
  'ai-colorization': { tier: 'ai-product', credits: 0 },
  'ai-enhancement': { tier: 'ai-product', credits: 0 },
  'ai-text-to-speech': { tier: 'ai-product', credits: 0 },
  'ai-cutout-pro': { tier: 'ai-product', credits: 0 },
  'director-ai-agents': { tier: 'ai-product', credits: 0 },
  'director-advanced-agents': { tier: 'ai-product', credits: 0 },
};
```

#### Layer 2: User Subscription Service (`src/lib/subscriptionService.js`)
- Manages user subscription state
- Handles purchase/license key validation
- Tracks purchased products
- Provides subscription status API

#### Layer 3: UI Gate Components (`src/components/FeatureGate.jsx`)
```jsx
<FeatureGate feature="timeline-editor">
  <TimelineEditor />
</FeatureGate>

<FeatureGate feature="ai-product">
  <AIPanel />
</FeatureGate>
```

#### Layer 4: Router Integration (`src/lib/routedWithGating.js`)
- Checks purchase status before route navigation
- Shows upgrade prompts for gated features
- Redirects to pricing page when needed

## Migration Notes

1. **Existing Users**: All existing users get free access to Director Editing for 30 days
2. **Watermark**: Free tier exports include subtle watermark
3. **AI Credits**: No credit system - AI product is unlimited when purchased
4. **Backward Compatibility**: Existing routes still work, gates add restrictions
5. **Director**: Now a standalone app product, not tier-gated

## Success Metrics

1. Conversion rate from free to paid products
2. AI product adoption rate
3. Individual app purchase rates
4. Revenue per user (ARPU)
5. Bundle upsell rate

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Users bypass gates | Server-side validation for all API calls |
| Complex migration | Feature flags default to current behavior |
| Revenue impact | 30-day free access to Director for existing users |
| Performance overhead | Cache subscription state, lazy load checks |
