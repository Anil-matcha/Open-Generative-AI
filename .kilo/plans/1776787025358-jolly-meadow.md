# AI-VFX Standalone App Integration Plan

## Overview
Integrate the AI-VFX application from https://github.com/SamurAIGPT/AI-VFX as a standalone app within the Open Higgsfield repository, following the same pattern as the remix-go app. This creates an independent AI video effects generator that users can access without touching the main timeline editor.

## Current Repository Structure Analysis
- **Monorepo Pattern**: Uses workspaces with apps/* structure
- **Hosting**: Apps are built to public/apps/{app-name}/ and served from /apps/{app-name}/
- **Existing Apps**: remix-go, vimax, director all follow this pattern
- **MuAPI Integration**: Extensive existing VFX API support in src/lib/muapi.js and MuAPIAdvancedEffects.js

## Implementation Plan

**Objective**: Set up the basic standalone app structure following monorepo patterns

**Tasks**:

## Technical Architecture

### Framework Migration
- **Source**: Next.js 15 with App Router
- **Target**: Vite + React 18
- **Key Changes**:
  - Convert app/ directory to src/components/
  - Replace Next.js routing with React Router
  - Adapt server components to client components
  - Convert TailwindCSS v4 configuration

### API Architecture
- **Existing MuAPI**: Full VFX support already available
- **Integration**: Standalone client with localStorage API key
- **Endpoints**: WAN AI effects, video generation, file upload
- **Error Handling**: Comprehensive retry and fallback logic

### Hosting Strategy
- **Pattern**: Follow remix-go app structure
- **Build Output**: public/apps/ai-vfx/
- **Access URL**: /apps/ai-vfx/ (or ai-vfx.yourdomain.com)
- **Independence**: No dependency on main timeline editor

## Build Configuration

### vite.config.js
```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5174 // Separate from main app
  },
  build: {
    outDir: '../../public/apps/ai-vfx',
    emptyOutDir: true
  }
})
```

### Root Package.json Scripts
```json
{
  "dev:ai-vfx": "cd apps/ai-vfx && npm run dev",
  "build:ai-vfx": "cd apps/ai-vfx && npm run build",
  "build:all": "npm run build:remix-go && npm run build:ai-vfx && npm run build"
}
```
