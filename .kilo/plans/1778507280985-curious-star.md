## Superpowers Workflow Implementation

### Phase 1: Brainstorming & Design (Superpowers Step 1)
**Objective**: Refine verification methodology for AI-generated image authentication

**Brainstorming Questions**:
- How can we programmatically detect if an image is AI-generated vs. a copied placeholder?
  - File size analysis: Real AI images typically have varied file sizes
  - Content hashing: md5sum comparison to detect exact duplicates
  - Visual pattern analysis: AI images have characteristic patterns vs. simple copies
- What constitutes a "genuine" AI-generated hero image?
  - Unique visual content relevant to studio function
  - High-resolution suitable for hero banner display
  - Proper WebP format with reasonable file size
- How should we handle the replacement strategy?
  - Prioritize by studio importance (image, video, effects, etc.)
  - Test each replacement before bulk updating
  - Maintain backup of original files

**Design Decision**: Use three-layer verification:
1. **File Integrity**: Hash comparison to detect duplicates
2. **Content Authenticity**: Visual inspection for AI characteristics  
3. **Functional Relevance**: Content matches studio purpose

```javascript
describe('Hero Image Verification', () => {
  test('All 34 hero images exist in filesystem', () => {
    const fs = require('fs');
    const path = require('path');
    const heroDir = 'public/thumbnails/heroes';
    const files = fs.readdirSync(heroDir).filter(f => f.endsWith('.webp') || f.endsWith('.png'));
    expect(files.length).toBe(34); // Expected hero count
  });

  test('No duplicate images detected (md5 hash comparison)', () => {
    const { execSync } = require('child_process');
    const result = execSync('cd public/thumbnails/heroes && md5sum * | sort | uniq -w32 -D').toString();
    expect(result.trim()).toBe(''); // Empty = no duplicates
  });

  test('Each studio has unique image path', () => {
    const { getHeroThumbnail } = require('../../src/lib/thumbnails.js');
    const studios = ['image', 'video', 'cinema', 'storyboard', 'effects', 'edit', 'upscale',
                   'character', 'commercial', 'influencer', 'audio', 'avatar', 'training',
                   'videotools', 'render', 'chat', 'advanced-dubbing', 'templates', 'ai-vfx',
                   'runway-motion', 'tiktok-carousel', 'headshots', 'vfx', 'video-agent',
                   'video-outreach', 'director', 'timeline', 'sendspark', 'remix-go', 'marketing-studio'];
    const paths = studios.map(s => getHeroThumbnail(s)).filter(Boolean);
    const uniquePaths = [...new Set(paths)];
    expect(paths.length).toBe(uniquePaths.length);
  });

  test('Images are loadable and valid WebP/PNG format', () => {
    // Check file headers for valid image formats
    const fs = require('fs');
    const files = fs.readdirSync('public/thumbnails/heroes');
    files.forEach(file => {
      if (file.endsWith('.webp') || file.endsWith('.png')) {
        const filePath = `public/thumbnails/heroes/${file}`;
        const buffer = fs.readFileSync(filePath);
        // WebP: RIFF + WEBP, PNG: \x89PNG
        const isValid = buffer.toString('ascii', 0, 4) === 'RIFF' ||
                        buffer.toString('hex', 0, 8) === '89504e470d0a1a0a';
        expect(isValid).toBe(true);
      }
    });
  });
});
```
