# Web-Compatible LTX-Desktop Features Integration Plan

## Executive Summary
This plan enhances the openhiggsfield platform with LTX-Desktop features, integrating advanced AI generation and editing capabilities across the timeline editor and supporting applications (CutAI backend and ViMax app). All enhancements maintain existing functionality while adding LTX capabilities with consistent design system integration.

## Current State Assessment (Full Ecosystem)
- ✅ **Timeline Editor**: Fully implemented with advanced editing features
- ✅ **AI Generation**: MuAPI integration with multiple providers
- ✅ **LTX Basic Integration**: Text-to-video, image-to-video, retake functional (40% complete)
- ❌ **Internal Packages**: @higgsfield/layout, @higgsfield/navigation, @higgsfield/tokens not built
- ❌ **CutAI Backend**: AI-powered video processing not installed (needed for gap fill)
- ❌ **ViMax App**: Agentic video generation not installed (needed for multi-take generation)
- ❌ **LTX Advanced Features**: Multi-take versioning, gap fill, XML import/export, audio-to-video (60% missing)

## Design System Integration Guidelines

### Theme Selection & Application
- **Primary Theme**: Use "electric" theme (#2B61FF blue) for all LTX components
- **Theme Application**: Apply via CSS classes and ThemeService integration
- **Consistent Branding**: LTX components should match app's dark tech aesthetic
- **Theme Switching**: Support dynamic theme changes without breaking LTX features

### Component Styling Standards
- **Glass Morphism**: Use `.glass` and `.glass-panel` classes for modals and overlays
- **Interactive Elements**: Apply `.interactive-glow` for buttons and controls
- **Card Patterns**: Follow `.style-card` structure with aspect ratios
- **Form Elements**: Use `.prompt-field` styling for input components

### Visual Consistency Requirements
- **Color Variables**: Use CSS custom properties instead of hardcoded colors
- **Typography**: Follow Inter font family with established scale
- **Spacing & Layout**: Use Tailwind utilities with custom breakpoints
- **Accessibility**: Maintain ARIA roles, focus management, and keyboard navigation

### Embedding & Integration Patterns
- **Component Structure**: Integrate directly into existing app shell (sidebar, content area)
- **Iframe Usage**: Use secure iframe pattern for isolated components if needed
- **MuAPI Embed Integration**: Adapt the provided embed code to match app theming
- **Cross-App Communication**: Leverage CustomEvent system for app coordination
- **Responsive Design**: Ensure mobile compatibility with existing breakpoints

### MuAPI Embed Code Integration
- **Embed Source**: `https://muapi.ai/embed/727957e1-7b37-418f-b9e5-efbc1417ea2f`
- **Styling Requirements**: Apply electric theme colors and glass morphism effects
- **Responsive Container**: Use aspect ratio containers with proper breakpoints
- **Theme Synchronization**: Ensure embed inherits app's color scheme and dark mode
- **Secure Implementation**: Use existing secure iframe creation utilities
