# Cinematic App Thumbnails - Generation Prompts

Following the "Centered Luminance" Design Philosophy

## Design Philosophy Summary

**Centered Luminance** emphasizes:
- Subjects positioned at absolute center with architectural precision
- Deep atmospheric dark backgrounds (charcoal, midnight blue, obsidian)
- Sculpted lighting: key light, rim lighting, subtle fill
- Restrained sophisticated color palette with controlled saturation
- Cinematic 16:9 aspect ratio
- Master-level craftsmanship in every detail

## Generation Instructions

1. Use MuAPI with Flux Schnell or Flux Pro model
2. Set aspect_ratio to "16:9"
3. Add quality enhancers: "cinematic quality, professional photography, high resolution, centered subject"
4. Expected output: 640×360 or 1280×720 pixels
5. Save as .webp format for optimal web performance

## Output Locations

All thumbnails should be saved to:
